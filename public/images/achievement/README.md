# Achievement reference artwork

The PNGs are unchanged copies of the user's supplied achievement reference images.
`AchievementArt.jsx` uses SVG viewports to display individual illustrations. All text,
progress, tabs, and buttons remain live, responsive HTML.

Badge progress uses saved rewards, including the migrated gamification store. The
existing accuracy badges retain their gems-based progress proxy. Existing certificate
preview and PNG/PDF export are retained. The five reference assessments absent from
the curriculum are explicitly disabled coming-soon cards, without invented quiz data.
