# Leaderboard artwork

`reference.png` is the user-supplied `Leaderboard mobile version.png`, copied unchanged.
`LeaderboardHome.jsx` displays individual illustration windows using SVG view boxes;
headings, tabs, scores, names, and the table are responsive HTML, not a screenshot overlay.

Rankings use explicitly labeled demonstration data because the project has no remote
leaderboard service. Subject tabs select the preview context; each currently uses the
same reference sample. The device's real global stars are shown separately when nonzero.
